# data

Only small samples and descriptions are stored here. Large rasters are downloaded by the pipeline into `data/raw/` (ignored by Git).

| Dataset | Use | Source |
|---|---|---|
| Copernicus DEM GLO-30 | Elevation, slope, TWI | Copernicus |
| Sentinel-1 SAR (April 2024) | Flood extents for training and validation | ESA, via Google Earth Engine |
| ESA WorldCover | Land cover | ESA |
| SoilGrids | Soil type | ISRIC |
| OpenStreetMap | Rivers, roads, geocoding | OSM |
